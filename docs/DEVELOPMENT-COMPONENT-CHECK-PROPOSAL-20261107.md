# Development component check-only proposal

This is an unprotected validation proposal. It does not install a PR gate, replace any existing check, approve a PR, merge a branch, select a hosted target or deploy code. Root retains all application review and approval authority.

The selector accepts only the five recorded Development component requests in deployment/development-component-counterparts.json. It refuses release, production, JWT, database/schema effects, forks, changed PR heads, deployment-control changes and floating counterpart refs. The only permitted existing checker delta is the independently reviewed exact SQL-identifier classifier blob.

Counterparts are immutable repository/SHA pins. The public workflow demonstrates Studio PR5's ACTUAL current source d302670e against Academy87bf3daa, using the independently reviewed full checker28314ca7 in check mode. Its result is a PROPOSAL proof, never a green replacement for a failing original PR check or an optimisation approval.

The actual PR source checkout stays unchanged. Fresh disposable worktrees generate separately identified V109.27 packages if the inputs only retain V109.25. Evidence records the actual input commit/tree, counterpart, checker, generated package commit/tree, manifest hash and each source version-stamp transformation. Existing V109.25 trees and all hosting/approval/binding controls must remain unchanged. If an input retains only the reviewed V109.25 manifest and no Git package tree, evidence preserves that exact absence and the original input-manifest blob/hash; it never fabricates or overwrites an old package tree. Run42348901753/archive13565185307 retains the exact generated public bytes. A later proof with the identical actual Studio source, Academy counterpart and package-builder pin keeps its own fresh source/package identities and manifest maps, with an explicit reference to those raw bytes. The earlier run is not represented as proof of a later adapter source; map equality is required before reusing any archived bytes. A different source/public map requires new raw evidence. Generated package commits are ephemeral and never pushed. The complete existing checker still enforces source/public byte equality, exact shared modules, credential scanning, all named paired groups, route checks and bundles. No private environment or Cloudflare credential is available.

Academy PR6 retains the already-green native Studio baseline. PR8 selects a minimal Studio counterpart with only the same-tab native fixture correction. PR7 selects the reader-only plus same-tab counterpart; its current source must first include accepted PR8 navigation or preflight fails with DEPENDENCY_ACADEMY_SAME_TAB. PR12 selects complete reviewed Studio UI003; its current source must include the reviewed reader/same-tab composition or exact shared-module preflight fails. These dependencies remain blockers; the selector does not broaden parity.

After Root accepts this concrete proposal, a caller can check out the immutable accepted control commit on its actual pull_request event, supply its own repository/PR number, run select/stage/package, supply the literal accepted COMPONENT_CONTROL_REF, invoke the adapter's check phase (which verifies both clean immutable control/checker checkouts and invokes the literal full checker in check mode) and verify. The actual event head must equal the fresh GitHub PR head before source work and after the full check. The caller must remain read-only, without environment credentials or status/merge/deploy steps. Root must review that concrete caller before installation. No production/release dispatch file is changed by this proposal.

Before every later phase, the saved selection is rebound to the literal registry and the actual caller/event source. Before and after the full checker, the generated tree is compared with its original source: only the declared package metadata/public directory and exact Academy version-only transformations are permitted. Stored evidence is never allowed to redirect a checker or counterpart pin or disguise changed app source.
