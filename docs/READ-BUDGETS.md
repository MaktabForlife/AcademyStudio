# Local database-read evidence

Measured on 28 October 2026 using native disposable Workers D1, not a mocked database. The automated regression is `tests/read-budgets.test.mjs`; its full measured output is `outputs/read-budgets.json` (regenerated by the test). Each request includes account checks, queries, atomic mutation guards, operation receipts and audit inserts. Counts are D1's reported rows read, not the number of returned rows or HTTP requests.

The comparison adds 4,000 unrelated records to each of accounts, offerings, participation, websites, cards, announcements, timetable and attachments. No hosted database is queried. A small increase in index traversal is permitted; scanning the unrelated population fails the test. This is a synthetic regression, not a provider quota estimate or proof for every real data distribution.

Public cards/announcements and global upcoming-session preparation have dedicated indexes. Saves check website asset ownership in a single scoped query, rather than one request per asset. Rights discovery starts with indexed account rights and checks the specific Surah completion month; Global Admin discovery is paginated separately. Routine protected routes make no Academy calls, as verified by a fixture that rejects all such outbound calls.

Source synchronization uses indexed per-account pending events, bounded 40-event pages and at most four pages per command. Recovery examines at most 20 candidates per run (configurable maximum 40), preserves per-stream order and backs off failures. Source session-revocation lookup is indexed. No all-account status sweep or per-tab polling has been introduced.

Still required before migration acceptance: source authentication/coordinator and trigger read accounting; source timetable/Zoom export and replay budgets; identity provisioning/recovery, large accepted asset-reference sets and bulk paid-month budgets; actual migrated access distributions; aggregate daily traffic/retry estimates; object-request costs; and cleanup/reconciliation budgets. Keep these separate from the target-only measurements above. Never remove current authority checks merely to meet a numerical budget.
