- Block real target API access first (`PLATFORM_ENABLED=0`, or a tested equally complete real-integration gate), so existing website cookies cannot continue with stale mirrored authority. Already downloaded files or disclosed Zoom URLs cannot be recalled by a feature flag.
- Set source `website_platform_control.enabled=0` to stop trigger capture/recovery, then disable `ACADEMY_WEB_PLATFORM`/revert the connector Worker/static release as required. Leave existing Academy delivery/routes intact. Changing only the environment flag does not turn off database triggers while the database control remains enabled.

Do not delete accounts, drop shared tables, restore an old whole database, reseed rights or reset versions as a rollback shortcut.
